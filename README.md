# Simple Interest Calculator

## Explanation

This program calculates simple interest using the principal amount, rate of interest, and time.

## Problem Statement

Write a Python program to calculate simple interest and the total amount.

## Formula

```text
Simple Interest = (P × R × T) / 100
```

```text
Amount = P + Simple Interest
```

## Features

* Accepts principal amount
* Accepts interest rate
* Accepts time
* Calculates simple interest
* Calculates total amount

## How It Works

The program takes the principal, rate, and time as input and applies the simple-interest formula.

## Technologies Used

* Python 3

## Data Structure Used

* Floating-point variables

## Methods Used

* `input()`
* `float()`

## Program Flow

1. Read principal
2. Read rate
3. Read time
4. Calculate simple interest
5. Calculate total amount
6. Display results

## Sample Input

```text
Principal: 10000
Rate: 5
Time: 2
```

## Sample Output

```text
Simple Interest: 1000.0
Total Amount: 11000.0
```
